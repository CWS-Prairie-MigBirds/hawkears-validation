Run on your own WildTrax project

Export the main report and the AI report for an ARU project (WildTrax download, or wt_download_report(reports = c("main","ai")) then write_csv()). Files are processed in your browser and are not uploaded anywhere.

What the files need

Main report: recording_id, task_id, species_code, and ideally task_duration. AI report: recording_id, species_code, confidence, version, and ideally detection_time and is_species_allowed_in_project. Detections after the end of the listened task are ignored; species not allowed in the project are dropped; species humans tagged that the classifier never reports (unknowns, abiotic, out-of-model species) are not counted as misses.

How to read these results

The setup. For every task (one recording segment a person listened to) and every species, two questions get answered: did the person tag it, and did the classifier detect it? Each task × species combination is one unit.

Score. For each detection the classifier gives a number from 0 to 1: how confident it is. It isn't a probability, and a 0.7 for one species doesn't mean the same as a 0.7 for another.

Threshold. The cutoff you choose. Detections at or above it count as "the classifier says yes"; anything below is ignored.

Person tagged itPerson didn't
Classifier says yesTrue positive (TP)False positive (FP)
Classifier says noFalse negative (FN), a missTrue negative (not used)

Precision = TP ÷ (TP + FP). When the classifier says a species is there, how often is it right?

Recall = TP ÷ (TP + FN). Of the times a person heard the species, how often did the classifier catch it?

F-score combines the two into one number; it's only high when both are high.

The trade-off. Raising the threshold makes the classifier pickier: fewer false calls (precision up) but more misses (recall down). Every curve on this site shows that trade-off.

F-max vs. precision target. F-max is the threshold with the best balance between precision and recall. The precision target (default 0.90) is the lowest threshold where the classifier is right at least 90% of the time; use it if detections go straight into analyses without anyone checking them.

Caveats

Score floor. WildTrax only stores classifier scores above a minimum (0.30 for HawkEars in the project data). Curves are flat below it and nothing there can be evaluated; an F-max "at the floor" means the true best threshold could be lower.

People miss birds too. Some false positives are real birds nobody tagged, especially quiet or distant ones, so precision is a conservative estimate. Verify a sample of high-scoring false positives before concluding the classifier is wrong.

Small samples. Species with few human detections have noisy thresholds. The minimum-units filter on the species page controls this.

Not the same recall as wt_evaluate_classifier(). That function only counts misses among species–tasks the classifier detected at some score, so its recall starts at 1.0. Here, a human tag with no detection at all also counts as a miss.

Unit of evaluation: presence per unit × species. Built with WildTrax data and the wildrtrax R package.
